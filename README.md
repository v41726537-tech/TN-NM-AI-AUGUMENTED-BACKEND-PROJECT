# FitTrack AI - Augmented Backend Project

FitTrack AI is a backend REST API developed for the Naan Mudhalvan / SmartBridge program using Node.js, Express, MongoDB Atlas, JWT authentication, and Google Gemini AI.

## Features
- User Registration & JWT Authentication
- Google Gemini AI-driven Personalized Workout Plan Generation
- Workout Logging and Progress Tracking
- MongoDB Atlas Cloud Database Integration

## Tech Stack
- Node.js & Express.js
- MongoDB & Mongoose
- Google Gemini AI (@google/genai)
- JSON Web Token (JWT) & bcryptjs
